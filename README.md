# SMVRS Independent Verify | Proof Before Effect

**2027 Edison Awards Nominee — Public Technical Companion**

SMVRS (Signed Machine-Verifiable Record Systems & Services) explores portable signed records and independently implemented verification of supported evidence, identity, time, and policy relationships. The core question is how a receiving system can check relevant claims *before relying on them for consequential decisions*.

## Evidence and development status

- The examples described are **controlled inventor-run tests**, not independent production security certification.
- Two separate verifier implementations (Python and Node.js) are illustrated with passing and failing synthetic signed-record cases, including explainable failure reasons.
- Future protected-effect execution, production signing, and domain-specific regulated applications must not be understood as completed or approved production services.
- References to **1999** identify the early BEI / ATMS digital-infrastructure work. The reported **556** refers to records in a broader U.S. patent application portfolio, **not 556 granted patents**.
- Industry and user-group reach describes intended applicability, not proven worldwide deployment.
